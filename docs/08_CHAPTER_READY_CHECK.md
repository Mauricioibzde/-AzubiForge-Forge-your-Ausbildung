# Chapter Ready Check

Purpose: Help students decide whether they really understand a chapter.

This check is for the student, not only for the author.

---

## Core Question

Do I understand this topic well enough to use it in an AP1 task?

If the answer is no, the student should revise before continuing.

---

## Ready Check Questions

### 1. Can I explain this topic?

Ask:

- Can I explain it in simple German?
- Can I explain it without reading the text?
- Can I give a practical example?

If no:

Review the introduction, complete explanation and summary.

---

### 2. Can I recognize it in German?

Ask:

- Do I know the German technical terms?
- Can I understand example sentences?
- Can I recognize the term in a task?

If no:

Review the vocabulary table and write your own sentences.

---

### 3. Can I solve AP1 questions?

Ask:

- Can I solve easy exercises?
- Can I solve intermediate exercises?
- Can I solve AP1-style scenarios?
- Can I explain why my answer is correct?

If no:

Repeat exercises and read answer explanations.

---

### 4. Can I compare it to similar concepts?

Ask:

- What is this often confused with?
- Can I explain the difference?
- Can I give one example for each concept?

If no:

Review common mistakes and comparison sections.

---

### 5. Can I explain it without reading?

Ask:

- Can I close the chapter and explain the topic aloud?
- Can I draw a small diagram or mind map?
- Can I answer a scenario from memory?

If no:

Use active recall:

1. Close the chapter.
2. Write what you remember.
3. Compare with the summary.
4. Repeat later.

---

## Ready Levels

### Not Ready

The student recognizes some words but cannot explain or solve exercises.

Action:

Reread the explanation and vocabulary.

### Almost Ready

The student understands the explanation but struggles with AP1-style tasks.

Action:

Repeat practical examples and AP1 exercises.

### Ready

The student can explain, compare and solve AP1-style questions.

Action:

Mark chapter as completed and schedule revision.

---

## Final Student Checklist

- [ ] I can explain the topic in simple German.
- [ ] I can recognize important German terms.
- [ ] I can give a real-world example.
- [ ] I can compare it with similar concepts.
- [ ] I can solve AP1-style questions.
- [ ] I understand my mistakes.
- [ ] I can explain the topic without reading.

If any answer is NO:

Do not mark the chapter as fully ready.
