# Educational Depth Standard

Purpose: Define deep understanding without relying on word count.

---

## Core Principle

Chapter quality is not measured by length.

Chapter quality is measured by whether the student can understand, explain, apply and revise the concept.

A long chapter can be shallow.

A short chapter can be deep if it answers the right questions completely.

---

## The Ten Depth Questions

Every important concept must answer:

1. What is it?
2. Why does it exist?
3. Where is it used?
4. How does it work?
5. Why is it important?
6. What are common mistakes?
7. How does it compare with similar concepts?
8. When should it be used?
9. When should it not be used?
10. How does it appear in AP1?

If a concept does not answer these questions, it is not complete.

---

## 1. What Is It?

Give a simple definition.

The first definition must be beginner-friendly.

Example:

"RAM ist ein schneller Speicher, den der Computer während der Arbeit benutzt."

Do not start with complex technical language.

---

## 2. Why Does It Exist?

Explain the problem the concept solves.

Example:

RAM exists because the CPU needs fast access to data while programs run.

Without this part, students memorize terms without understanding purpose.

---

## 3. Where Is It Used?

Show real use in companies or daily IT work.

Example:

RAM is used when employees open browsers, IDEs, office programs or virtual machines.

---

## 4. How Does It Work?

Explain the mechanism step by step.

Use:

- Simple flow.
- Diagram when useful.
- Clear cause and effect.

Avoid unnecessary internal details if they do not help AP1.

---

## 5. Why Is It Important?

Connect the concept to:

- Performance.
- Security.
- Availability.
- Cost.
- Usability.
- Troubleshooting.
- AP1 relevance.

---

## 6. Common Mistakes

Every topic has traps.

Examples:

- RAM is confused with SSD.
- RAID is confused with backup.
- DNS is confused with DHCP.
- Authentication is confused with authorization.

Explain why the mistake happens and how to avoid it.

---

## 7. Comparison With Similar Concepts

Students learn better through contrast.

Every chapter should include comparisons when useful:

- RAM vs SSD.
- Switch vs Router.
- TCP vs UDP.
- Backup vs RAID.
- Primary key vs foreign key.

Comparisons must focus on AP1-level differences.

---

## 8. When Should It Be Used?

Explain practical decision criteria.

Example:

Use SSD when fast access time is important.

Use VPN when remote users need secure access to a company network.

---

## 9. When Should It Not Be Used?

This prevents blind memorization.

Example:

RAID should not be used as a replacement for backup.

UDP should not be used when reliable delivery is required.

---

## 10. How Does It Appear In AP1?

Explain likely exam patterns:

- Definition.
- Comparison.
- Scenario.
- Troubleshooting.
- Diagram assignment.
- Decision and justification.

This section turns technical knowledge into exam readiness.

---

## Depth Levels

### Level 1: Recognition

Student recognizes the term.

Not enough for chapter completion.

### Level 2: Explanation

Student can explain the term simply.

Minimum level for easy exercises.

### Level 3: Application

Student can apply the concept in a scenario.

Required for AP1 readiness.

### Level 4: Transfer

Student can use the concept in a new, mixed situation.

Premium learning target.

---

## Depth Checklist

Before accepting a chapter:

- [ ] Does each major concept answer the ten depth questions?
- [ ] Are similar concepts compared?
- [ ] Are common mistakes explained?
- [ ] Is AP1 relevance explicit?
- [ ] Can the student apply the concept?
- [ ] Can the student decide when it is suitable?
