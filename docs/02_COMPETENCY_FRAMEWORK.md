# AP1 FIAE Competency Framework

Scope: AP1 FIAE  
Purpose: Define what students must be able to do, beyond completing chapters.

---

## Why Competencies Matter

AzubiForge is not only a list of chapters. Each chapter must build one or more competencies.

A competency is an ability the student can use in a new situation.

Example:

Knowing the word "RAM" is not a competency.

Explaining why too little RAM slows down a workstation is a competency.

---

## Competency Levels

Each competency should develop through four levels:

1. Recognition  
   The student recognizes the German term.

2. Explanation  
   The student explains the concept simply.

3. Application  
   The student uses the concept in a scenario.

4. Exam Readiness  
   The student solves AP1-style questions and explains the answer.

## Competency Map

### Competency 1: Understand IT Foundations

The student can explain how computers process, store and exchange information.

Chapters:

- Einführung in AP1 und Lernstrategie
- EVA-Prinzip
- Binärsystem, Bits und Bytes
- Maßeinheiten

Evidence:

- Student can explain input, processing, output and storage.
- Student can distinguish bit and byte.
- Student can interpret simple size units.

---

### Competency 2: Understand Hardware

The student can explain the role of major computer components.

Sub-competencies:

- Understand what hardware is.
- Explain CPU.
- Explain RAM.
- Compare SSD and HDD.
- Explain mainboard.
- Explain power supply.
- Explain GPU.
- Identify peripheral devices.

Chapters:

- Was ist Hardware?
- CPU
- RAM / Arbeitsspeicher
- Speicher: SSD, HDD und Massenspeicher
- Mainboard
- Netzteil
- GPU
- Peripheriegeräte

Evidence:

- Student can identify which component affects which problem.
- Student can explain performance bottlenecks.
- Student can compare storage types.

---

### Competency 3: Understand Operating Systems

The student can explain how an operating system manages hardware, software and users.

Sub-competencies:

- Explain what an operating system is.
- Explain kernel.
- Understand boot process.
- Understand file systems.
- Explain processes and threads.
- Explain memory management.
- Explain users, groups and permissions.

Chapters:

- Was ist ein Betriebssystem?
- Kernel
- Boot-Prozess
- Dateisysteme
- Prozesse
- Threads
- Speicherverwaltung
- Benutzer und Gruppen
- Rechte und Berechtigungen

Evidence:

- Student can explain why OS exists.
- Student can distinguish process and thread.
- Student can explain permissions in workplace scenarios.

---

### Competency 4: Understand Networks

The student can explain how devices communicate in local and wide networks.

Sub-competencies:

- Explain LAN, WAN and WLAN.
- Explain switch and router.
- Explain IP addresses.
- Explain DNS and DHCP.
- Explain NAT and VPN.
- Explain ports, TCP and UDP.

Chapters:

- Was ist ein Netzwerk?
- LAN
- WAN
- WLAN
- Switch
- Router
- Firewall
- IP-Adressen
- Subnetze basics
- DNS
- DHCP
- NAT
- VPN
- Ports
- TCP
- UDP

Evidence:

- Student can troubleshoot simple connectivity problems.
- Student can distinguish DNS and DHCP.
- Student can explain the role of ports.

---

### Competency 5: Understand Layered Communication

The student can use OSI as a mental model for network communication and troubleshooting.

Chapters:

- Warum gibt es das OSI-Modell?
- Schicht 1 to Schicht 7
- OSI Troubleshooting
- OSI vs TCP/IP Modell

Evidence:

- Student can assign devices and protocols to layers.
- Student can reason from physical problems to application problems.

---

### Competency 6: Understand IT Security Basics

The student can explain basic protection goals, risks and measures.

Sub-competencies:

- Explain confidentiality, integrity and availability.
- Distinguish authentication and authorization.
- Explain password security and MFA.
- Recognize malware and phishing.
- Explain backup, RAID and encryption basics.

Chapters:

- Grundlagen der Informationssicherheit
- Vertraulichkeit, Integrität, Verfügbarkeit
- Authentifizierung und Autorisierung
- Passwörter und MFA
- Malware und Phishing
- Firewall basics
- Verschlüsselung basics
- Datenschutz basics
- Backup vs RAID

Evidence:

- Student can choose suitable security measures.
- Student can explain why RAID is not backup.

---

### Competency 7: Understand Data And Databases

The student can explain structured data and relational databases.

Sub-competencies:

- Explain database.
- Explain table, record and attribute.
- Explain primary and foreign keys.
- Understand relationships.
- Understand basic normalization.

Chapters:

- Was ist eine Datenbank?
- Tabellen, Datensätze und Attribute
- Primärschlüssel
- Fremdschlüssel
- Beziehungen
- Normalisierung basics

Evidence:

- Student can read simple database diagrams.
- Student can explain relationships between tables.

---

### Competency 8: Use Basic SQL

The student can read and write basic SQL statements relevant for AP1.

Chapters:

- SQL SELECT
- WHERE, ORDER BY
- JOIN basics
- INSERT, UPDATE, DELETE
- SQL AP1 practice

Evidence:

- Student can interpret SELECT statements.
- Student can filter data.
- Student can understand simple joins.

---

### Competency 9: Understand Programming Logic

The student can read simple logic and pseudocode.

Sub-competencies:

- Explain variables and data types.
- Use conditions.
- Understand loops.
- Understand functions/methods.
- Read arrays/lists.
- Find simple logic errors.

Chapters:

- Was ist Programmierung?
- Variablen und Datentypen
- Operatoren
- Bedingungen
- Schleifen
- Funktionen / Methoden
- Arrays / Listen
- Pseudocode lesen
- Fehler finden

Evidence:

- Student can trace simple pseudocode.
- Student can explain program flow.

---

### Competency 10: Understand Modeling

The student can read basic UML diagrams.

Chapters:

- UML Überblick

- Student can explain relationships and multiplicities.

---

### Competency 11: Solve AP1 Tasks

The student can combine knowledge across modules.

Sub-competencies:

- Read task verbs.
- Identify relevant data.
- Compare options.
- Justify decisions.
- Avoid common traps.

Chapters:

- Wie liest man AP1-Aufgaben?
- Signalwörter verstehen
- Tabellen und Diagramme auswerten
- Technische Entscheidungen begründen
- Mixed practice chapters

Evidence:

- Student can solve integrated AP1-style questions.
