# Module 0: Lernen, AP1 verstehen und AzubiForge benutzen

Purpose: Prepare students before Module 1.

Module 0 is mandatory. It teaches how to learn, how AP1 works and how to use AzubiForge effectively.

---

## Module 0 Goal

After Module 0, the student should be able to:

- Understand what AP1 is.
- Use AzubiForge as a study system.
- Read technical German more confidently.
- Learn vocabulary effectively.
- Answer AP1 questions strategically.
- Revise without forgetting.
- Decide whether a chapter is truly understood.

---

## Topic 1: Welcome

AzubiForge is a digital study book for AP1 FIAE.

It is not a social app.

It is not a game.

It is not a shortcut.

It is a structured learning system.

The goal is simple:

Understand AP1 topics deeply enough to answer exam questions with confidence.

---

## Topic 2: How AzubiForge Works

Each chapter contains:

- German explanation.
- Portuguese support.
- AP1 focus.
- Examples.
- Diagrams.
- Vocabulary.
- Exercises.
- Answers.
- Revision checklist.

The student should not rush.

One completed chapter should mean:

"Ich kann dieses Thema erklären und anwenden."

---

## Topic 3: How To Study Efficiently

Recommended process:

1. Read the title and objectives.
2. Read the introduction.
3. Study the complete explanation.
4. Write down vocabulary.
5. Understand examples.
6. Solve exercises without answers.
7. Read answer explanations.
8. Review mistakes.
9. Use the checklist.

Never study only by reading.

Learning requires retrieval:

The student must try to remember and explain without looking.

---

## Topic 4: How AP1 Works

AP1 uses professional situations.

The student must:

- Understand the situation.
- Recognize relevant concepts.
- Read German task verbs.
- Choose or write a suitable answer.
- Justify when required.

AP1 is not only memory. It is applied understanding.

---

## Topic 5: German Technical Vocabulary

Technical German is part of the exam.

Students should learn vocabulary in four columns:

| Deutsch | Português | Erklärung | Beispielsatz |
|---|---|---|---|

The example sentence is important because words in AP1 appear in context.

---

## Topic 6: Study Planning

Recommended weekly rhythm:

- 3 days for new chapters.
- 2 days for exercises.
- 1 day for revision.
- 1 day for weak topics.

Short daily sessions are better than long rare sessions.

Recommended session length:

- 25-45 minutes for beginners.
- 60-90 minutes for deep review.

---

## Topic 7: Revision Strategy

Use spaced revision:

- Same day: summary.
- Next day: vocabulary.
- After 1 week: exercises again.
- Before exam: AP1-style mixed tasks.

Revision should focus on:

- Mistakes.
- Confused concepts.
- German terms.
- Scenario questions.

---

## Topic 8: How To Read Technical German

Steps:

1. Find the verb.
2. Find technical nouns.
3. Identify what the task asks.
4. Translate only the key terms if needed.
5. Answer in simple German.

Common AP1 verbs:

- nennen
- erklären
- beschreiben
- begründen
- vergleichen
- zuordnen

---

## Topic 9: How To Answer AP1 Questions

Use the AP1 answer method:

1. Read the scenario.
2. Underline task verb.
3. Identify topic.
4. Recall definition.
5. Apply to scenario.
6. Answer clearly.
7. Add reason if required.

For "begründen", always write why.

For "vergleichen", always write at least one difference.

For "nennen", keep the answer short.

---

## Topic 10: How To Use The Glossary

Use the glossary:

- Before reading a chapter.
- During AP1-style exercises.
- During revision.
- When a German term blocks understanding.

Do not only translate words. Learn example sentences.

---

## Topic 11: How To Use Exercises

Correct order:

1. Try alone.
2. Write an answer.
3. Open solution.
4. Compare.
5. Understand explanation.
6. Note mistakes.

Do not open answers first.

That creates recognition, not learning.

---

## Topic 12: How To Review

A good review session includes:

- 5 vocabulary terms.
- 1 diagram.
- 3 easy questions.
- 2 intermediate questions.
- 1 AP1-style question.
- 1 self-explanation.

Self-explanation question:

"Wie würde ich dieses Thema einem anderen Azubi erklären?"

---

## Topic 13: How To Avoid Forgetting

Forgetting is normal.

To reduce forgetting:

- Repeat after time.
- Mix topics.
- Explain aloud.
- Solve exercises again.
- Keep a mistake list.
- Use German terms actively.

The goal is not to read more.

The goal is to retrieve better.

---
