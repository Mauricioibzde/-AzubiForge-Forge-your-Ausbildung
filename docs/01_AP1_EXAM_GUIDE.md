# AP1 Exam Guide

Scope: AP1 FIAE  
Purpose: Help beginners understand the AP1 journey before studying.

---

## What AP1 Is

AP1 means **Abschlussprüfung Teil 1**. It is the first official part of the final examination in the German Ausbildung.

For **Fachinformatiker für Anwendungsentwicklung (FIAE)**, AP1 checks whether the student understands the technical foundation of IT work. It is not only a programming exam. It includes hardware, operating systems, networks, security, databases, project work and basic professional situations.

AP1 is important because it tests whether the student can think like an IT professional in simple workplace scenarios.

Portuguese support: A AP1 não testa apenas programação. Ela testa fundamentos gerais de TI e a capacidade de entender situações técnicas em alemão.

---

## What The IHK Evaluates

The IHK usually evaluates:

- Understanding of IT fundamentals.
- Ability to read technical German.
- Ability to apply concepts in workplace situations.
- Ability to compare technical options.
- Ability to justify decisions.
- Ability to interpret tables, diagrams and short scenarios.
- Basic problem-solving.
- Correct use of technical vocabulary.

The IHK does not only ask: "What is X?"

It often asks:

- Which option is suitable?
- Why is this option suitable?
- What is the difference between two concepts?
- Which component causes this problem?
- Which term matches this description?
- Which measure improves security, performance or availability?

## Common Question Styles

### Definition

The student explains a term.

Example:

"Erklären Sie den Begriff Arbeitsspeicher."

### Comparison

The student compares two concepts.

Example:

"Vergleichen Sie HDD und SSD."

### Scenario

The student reads a company situation and chooses a solution.

Example:

"Ein Arbeitsplatz-PC startet sehr langsam. Nennen Sie zwei mögliche Ursachen."

### Problem Solving

The student identifies a cause or measure.

Example:

"Ein Client erhält keine IP-Adresse. Welche Dienste oder Einstellungen prüfen Sie?"

### Interpretation

The student reads a table, diagram or code snippet.

Example:

"Ordnen Sie die Geräte den passenden OSI-Schichten zu."

### Decision Making

The student chooses and justifies.

Example:

"Begründen Sie, warum ein Backup-Konzept trotz RAID notwendig ist."

## Common Task Verbs

| German Verb | Meaning | What The Student Must Do |
|---|---|---|
| nennen | citar/listar | Give short items, no long explanation needed. |
| beschreiben | descrever | Describe what something does or how it looks. |
| erklären | explicar | Explain meaning and relationship. |
| begründen | justificar | Give a reason for an answer or decision. |
| vergleichen | comparar | Show similarities and differences. |
| zuordnen | associar | Match terms, devices, layers or concepts. |
| beurteilen | avaliar | Judge a solution using criteria. |
| berechnen | calcular | Use numbers and formulas when required. |

Common mistake: Students answer "nennen" with too much text and "begründen" with too little explanation.

## How The Exam Is Structured

The exact structure can vary, but AP1 usually contains several practical tasks. The tasks are based on professional situations and require mixed knowledge.

A single task may combine:

- Hardware and operating systems.
- Network and security.
- Database and SQL.
- Programming and logic.
- Project documentation and communication.

Students should not study topics as isolated islands. They must learn connections.

---

## How Students Should Study

Recommended method:

1. Read the chapter in German.
2. Mark only important technical terms.
3. Use Portuguese support only when the concept is unclear.
4. Explain the topic aloud in simple German.
5. Solve easy exercises.
6. Solve intermediate exercises.
7. Solve AP1-style exercises.
8. Read the explanations.
9. Write down mistakes.
10. Revise after 1 day, 1 week and before the exam.

The most important rule:

Do not mark a chapter as ready only because it was read.

A chapter is ready when the student can explain and apply it.

## Typical Mistakes

- Learning definitions without understanding.
- Ignoring German technical vocabulary.
- Reading the question too quickly.
- Missing task verbs such as "begründen" or "vergleichen".
- Confusing similar terms: DNS/DHCP, RAM/SSD, Switch/Router, RAID/Backup.
- Not practicing AP1-style scenarios.
- Avoiding weak topics.
- Studying too many topics in one day without revision.
- Opening answers before trying exercises.

---

## Recommended Study Strategy

### Phase 1: Build Foundations

Study hardware, operating systems and networks first.

Reason: Later topics depend on these foundations.

### Phase 2: Build Connections

Connect topics:

- Hardware affects performance.
- Operating systems manage hardware.
- Networks connect systems.
- Security protects systems and data.
- Databases store structured data.
- Programs use all of these.

### Phase 3: Practice AP1 Thinking

Use scenario tasks:

- What is the problem?
- Which information is relevant?
- Which concept applies?
- Which answer is technically correct?
- How can I justify it?

---

## Revision Strategy

Use spaced repetition:

- Same day: short recap.
- Next day: vocabulary and summary.
- After 1 week: exercises again.
- Before exam: AP1-style mixed tasks.

Revision should include:

- Vocabulary.
- Common mistakes.
- Diagrams.
- Exercises.
- Self-explanation.

Best revision question:

"Kann ich das Thema ohne den Text erklären?"

---

## Exam Day Tips

- Read the whole task first.
- Underline task verbs.
- Mark technical terms.
- Watch for numbers, constraints and context.
- Answer exactly what is asked.
- Give reasons when the task says "begründen".
- Do not write unnecessarily long answers.
- If unsure, eliminate clearly wrong options.
- Keep time under control.
- Return to difficult tasks later.

Mindset:

The AP1 rewards structured thinking more than panic memorization.
