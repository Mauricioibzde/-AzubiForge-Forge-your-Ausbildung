# AzubiForge — Planejamento de Aprendizagem

Este pacote contém prompts e especificações em Markdown para transformar o AzubiForge em um sistema local, offline-first e sem custos recorrentes.

## Princípios do projeto

- Sem inteligência artificial em tempo real
- Sem APIs externas
- Sem serviços pagos
- Conteúdo local em `data.js` ou módulos JavaScript
- Progresso salvo em `IndexedDB` ou `localStorage`
- Correção determinística
- Planejamento diário e semanal
- Missões, competências, testes e revisões
- Compatibilidade com a estrutura atual da aplicação
- Migração gradual sem apagar conteúdo existente

## Arquivos

1. `01_prompt_mestre.md` — Prompt principal com toda a visão do sistema
2. `02_arquitetura_pedagogica.md` — Estrutura de curso, missões e domínio
3. `03_planejamento_diario_semanal.md` — Planejador local e sessões de estudo
4. `04_revisao_testes_simulados.md` — Revisão espaçada, testes e simulados
5. `05_estrutura_data_js.md` — Schemas e organização dos dados
6. `06_interface_componentes.md` — Interface, componentes e organização visual
7. `07_plano_implementacao.md` — Fases de implementação
8. `08_prompts_por_fase.md` — Prompts menores para executar etapa por etapa
9. `09_criterios_de_qualidade.md` — Checklist de conclusão
