# Critérios de qualidade

A implementação só será considerada concluída quando:

- [ ] o usuário souber exatamente o que fazer hoje;
- [ ] toda missão tiver um objetivo explícito;
- [ ] toda missão possuir critérios claros de conclusão;
- [ ] abrir uma página não significar concluí-la;
- [ ] estudo e domínio forem indicadores separados;
- [ ] o teste de domínio controlar a progressão;
- [ ] falhas gerarem revisão direcionada;
- [ ] revisões futuras forem agendadas localmente;
- [ ] o planejamento respeitar o tempo disponível;
- [ ] tarefas atrasadas forem reorganizadas;
- [ ] o progresso sobreviver ao fechamento da aplicação;
- [ ] tudo funcionar sem internet;
- [ ] nenhuma funcionalidade depender de IA;
- [ ] nenhum serviço pago for necessário;
- [ ] os dados continuarem editáveis em JavaScript;
- [ ] novos Lernfelder puderem ser adicionados sem alterar a lógica;
- [ ] novas missões puderem ser adicionadas sem alterar componentes;
- [ ] o sistema possuir migração ou adapter para dados antigos;
- [ ] as transições de estado forem testáveis;
- [ ] o planejador explicar por que escolheu cada tarefa;
- [ ] progresso, domínio e retenção forem apresentados separadamente;
- [ ] respostas abertas não fingirem correção automática;
- [ ] simulados puderem usar erros anteriores;
- [ ] revisões vencidas tiverem prioridade;
- [ ] a interface continuar compreensível sem efeitos visuais.
